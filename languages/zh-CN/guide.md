# Mainland Simplified Chinese (zh-CN) language guide

Mainland Simplified Chinese belongs to the Chinese family. Read `../zh/guide.md` first for
everything shared with Taiwan Traditional Chinese (`zh-TW`); this file states only what is
distinct. Readers are in Mainland China. Register and voice are nearly identical to
`zh-TW`; the deliberate differences are script, quotation-mark glyphs, particle
calibration, and the lexical splits recorded in `glossary.md`. Keep those splits and no
others.

## Script

Write in **Simplified Chinese characters** throughout. Never mix in Traditional characters.

## Register (zh-CN specifics)

- 你 throughout, never 您.
- **Use sentence-final particles (吧, 呢, 哦) sparingly**, more sparingly than `zh-TW` does.
  A particle is fine for a genuine invitation (试试吧！) but should not be reached for by
  default; the default register is plainer and more matter-of-fact.

## Quotation marks

Use curly quotation marks **“ ”** for Chinese-language quotation.

## Worked examples

Concrete Mainland Simplified Chinese for the principles in `global/voice.md`.

**Natural phrasing** (good vs stiff/literal):
- "First, define a function" → 首先，定义一个函数（not the stiff, over-explained
  第一步，我们需要定义一个函数）
- "Try running this code" → 试着运行这段代码
- "Let's begin" → 我们开始吧

**Common EN→zh-CN pitfalls:**
- English "it" as subject → drop it where Chinese doesn't need an explicit subject: "it
  returns a value" → 返回一个值 / 这个函数返回一个值
- Do not add 的 chains that stack more than two or three modifiers deep; recast as a
  shorter sentence instead
